Política de privacidad

Última actualización: 1 de octubre de 2026

Qué es

Finanzas Lucas es una herramienta de uso personal. Solo la usa su autor, con su propia cuenta de Google.

Qué datos accede

Con el permiso https://www.googleapis.com/auth/gmail.readonly, la aplicación lee los correos de notificación enviados por el banco del usuario (cargos, transferencias, pagos) para extraer monto, fecha, comercio y cuenta de cada transacción. No envía, modifica ni borra correos.

Cómo se usan y guardan

  • Los datos se procesan y almacenan únicamente en el computador del usuario, en una base de datos local.
  • No se envían a servidores del autor ni de terceros.
  • No se venden, comparten ni usan para publicidad.
  • El token de acceso de Google se guarda solo en ese computador.

Uso limitado

El uso y la transferencia de información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso y borrar los datos

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions. Borrar la base de datos local y el token elimina todos los datos obtenidos.
